Thực hành SASS bằng npm & SASS CLI

Minh họa biến, mixin, nesting, biên dịch một file và biên dịch theo thư mục.

Xem nội dung thực hành

Các nội dung đã thực hiện

01

Kiểm tra Node.js & npm

node -v npm -v
02

Cài đặt SASS

npm install npx sass --version
03

Biên dịch SCSS sang CSS

npm run sass
04

Chế độ theo dõi

npm run watch
05

Biên dịch nhiều file

npm run build

Ví dụ SCSS đang được áp dụng

Trang này sử dụng biến màu sắc, mixin dùng lại, cú pháp lồng và responsive được viết trong thư mục scss/.

SASS giúp CSS dễ tổ chức và bảo trì hơn.
